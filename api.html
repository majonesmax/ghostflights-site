Ghostflights API

The Ghostflights API gives you the flights on Ghostflights as data. Departed airlines fly their real 1985 timetables (1979 for Hughes Airwest and Braniff) and the API tells you where each flight is at any moment.

What it is

It answers the questions you'd ask a flight tracking feed. What's in the air near this place right now? Where are Pan Am's 747s? What's leaving Minneapolis in the next hour? The schedules are real. The positions are simulated along each route from its timetable times.

It is not real traffic and it can't be mistaken for it:

  • Every record has "simulated": true and the year it's set in.
  • There's no ICAO address on anything, so nothing can be fed into a real tracker.
  • Flight numbers are only ones a timetable printed. There are no tail numbers because the timetables don't list them.
  • Only airlines that no longer fly appear. No airline flying today shows up.

How it works

The API is a JavaScript library, not a web service. There's no server, no API key and no network request after you load it. It's two files:

FileSizeWhat it holds
feed-data.js450 KBEvery airline's schedule and the airports' positions
feed.js14 KBThe engine that works out where each flight is

Each query is for a point in time. The engine selects the flights scheduled to be airborne at that time. Each position is interpolated along the great-circle route between origin and destination by the share of the scheduled block time that has elapsed. The calculation is deterministic. The same query for the same time always returns the same result. Every client therefore shows the same flights without a shared server.

Load it in a page:

<script src="https://ghostflights.tv/feed-data.js"></script>
<script src="https://ghostflights.tv/feed.js"></script>
<script>
  const nearby = Ghostflights.query({ lat: 44.88, lon: -93.22, radius: 150 });
</script>

Or in Node, with both files downloaded next to your script:

require('./feed-data.js');
require('./feed.js');
const { query } = globalThis.Ghostflights;
console.log(query({ airline: 'Pan Am', type: '747' }));

Reference

Times can be milliseconds since 1970, a Date or an ISO 8601 string like "2026-11-27T02:00Z". Leave a time out to mean now. Distances are in nautical miles.

Ghostflights.query(options)

Returns the flights in the air at one moment that match every option you give, as an array of records.

OptionTypeMeaning
attimeThe moment to ask about. Default: now.
lat, lonnumberA place. Results are sorted nearest first and each gets distanceNm.
radiusnumberHow far from the place to look. Default: 100.
airlinestringIts code (PA1927), its two-letter designator (PA) or part of its name (Pan Am).
typestringA type code (B742) or name (747).
flightstring or number"NW 17", "NW17" or 17.
from, tostringOrigin or destination airport code.
phasestringclimbing, cruising or descending.
minAltFt, maxAltFtnumberAn altitude range in feet.
limitnumberReturn at most this many.

Ghostflights.feed(time)

Returns every flight in the air at that moment, with no filtering. Expect several hundred to about a thousand records. It's the same as query({ at: time }).

const everything = Ghostflights.feed();

Ghostflights.flights(options)

Returns the scheduled legs that are in the air at any point between start and end, with their departure and arrival times. Use it for an airport's arrivals and departures. It takes the same airline, type, flight, from, to and limit options as query.

OptionTypeMeaning
starttimeThe start of the window. Default: now.
endtimeThe end of the window. Default: one hour after start.
Ghostflights.flights({ from: 'MSP', limit: 1 })
[

    "simulated": true,
    "year": 1985,
    "flight": "NW 758",

    "typeCode": "B722",
    "from": "MSP",

    "departedThen": "1985-11-26T23:25Z",

  }
]

Ghostflights.track(flight, options)

Returns one flight's position at regular steps between start and end, like a track log. Each entry is a record with an at time added. Moments when the flight isn't airborne are skipped.

OptionTypeMeaning
starttimeDefault: now.
endtimeDefault: one hour after start.
everynumberSeconds between positions. Default: 60.
Ghostflights.track('NW 17', { every: 300 })

Ghostflights.adsb(options)

Takes the same options as query and returns the answer in the JSON shape of ADS-B receivers and aggregators like adsb.lol and ADS-B Exchange, so code written for them can read it. It's still marked simulated and still has no hex address.

Where it comes from


    
  
  • Northwest Orient: the system timetable of October 27, 1985, from the Northwest Airlines History Center.
    • 
  
  • Republic: city schedules from 1984 to 1986, from the Northwest Airlines History Center.
    • 
  
  • Pan Am: its own system timetable of February 15, 1985, from the University of Miami Libraries' Pan Am collection.
    • 
  
  • Muse Air: its own system timetable of July 20, 1985 as scanned at departedflights.com. It doesn't list aircraft. Types come from the February guide by flight or by route.
    • 
  
  • The rest: the Official Airline Guide of February 15, 1985 (November 15, 1979 for Hughes Airwest and Braniff International) as transcribed at departedflights.com.
    • 



Each flight runs on the weekday it flew in its year for today's date. Positions follow the great circle between the two airports. Altitude and speed are estimates from the distance and the scheduled time.
